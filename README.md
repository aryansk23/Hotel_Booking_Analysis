# Hotel_Booking_Analysis

This notebook performs an exploratory data analysis (EDA) on hotel booking data to uncover patterns in guest behavior, booking trends, cancellations, and revenue metrics.


 🔍 Key Objectives:
Understand booking distributions by hotel type and seasonality.

Analyze cancellation trends and their predictors.

Explore guest demographics, booking channels, and special requests.

Investigate average daily rates (ADR) and factors affecting revenue.


 📌 Main Findings:
City hotels have higher cancellation rates than resort hotels.

Longer lead times are linked with increased cancellations.

Repeat guests and those with special requests are more likely to show up.

Online travel agents dominate bookings but contribute more to cancellations.

Peak bookings and ADR occur during summer months.


 📦 Tools Used:
Python (Jupyter Notebook)

Libraries: pandas, seaborn, matplotlib, numpy
